# 💳 Финансовый аудит расходов

Веб-аппка, которая берёт выписку по карте, сама узнаёт мерчантов (Rimi, Maxima, Lidl, Bolt, Wolt, аптеки, коммуналка и т.д.) и раскладывает траты по категориям: графики по месяцам, разбивка по категориям, топ мерчантов, поиск по транзакциям.

**Приватность:** всё считается локально в браузере. Файлы никуда не загружаются, данные хранятся только в localStorage твоего браузера.

## Как пользоваться

1. Открой `index.html` в браузере (двойной клик по файлу — этого достаточно, сервер не нужен).
2. Перетащи CSV-выписку в окно или нажми «Выбрать файлы». Можно несколько файлов сразу — дубликаты отсеются автоматически.
3. Смотри аудит: KPI, расходы по месяцам, категории, топ мерчантов.
4. Если категория определена неверно — поменяй её в таблице транзакций: правило запомнится для этого мерчанта навсегда (в этом браузере).
5. «⬇ Экспорт CSV» — выгрузка всех транзакций с категориями (открывается в Excel/Numbers).

Кнопка «Попробовать на демо-данных» показывает аппку на сгенерированных рижских тратах.

## Поддерживаемые выписки

| Банк | Как выгрузить |
|---|---|
| **Swedbank** | Интернет-банк → Konts → Konta pārskats → период → *Saglabāt kā CSV* |
| **SEB** | Интернет-банк → Konta pārskats → период → CSV |
| **Revolut** | Приложение → счёт → Statement → Excel (CSV) |
| **Другой банк** | Почти любой CSV: аппка сама находит колонки даты, суммы и описания |

Понимает `;` и `,` как разделители, кодировки UTF-8 и Windows-1257 (балтийская), суммы с запятой (`12,50`) и точкой (`12.50`), даты `dd.mm.yyyy` и `yyyy-mm-dd`, колонку Debets/Kredīts.

## 🧺 Продуктовая корзина (что именно куплено в Rimi/Maxima)

В банковской выписке товаров нет — только сумма и магазин. Для детального анализа аппка принимает чеки:

- **Текст э-чека** из Mans Rimi / приложения Maxima — вставляешь, парсер разбирает локально: позиции, цены, скидки (строки Atlaide), депозит. Бесплатно, офлайн.
- **Фото или PDF чека** — распознаётся через Claude API с твоим ключом Anthropic (кнопка ⚙️ в разделе корзины). Работает для любого магазина, включая Lidl. Ключ хранится только в браузере; на сервер уходят только загруженные тобой чеки.

Товары раскладываются по категориям (молочка, мясо, овощи-фрукты, сладости, алкоголь, бытовая химия и т.д. — словарь латышских названий в `js/products.js`), считается топ товаров, а чеки автоматически сопоставляются с транзакциями из выписки по сумме и дате. Категорию товара можно поправить вручную — правило запомнится.

## Категории

Продукты · Кафе и рестораны · Доставка еды · Транспорт · Авто и топливо · Аптеки и здоровье · Красота · Одежда · Дом и быт · Электроника · Подписки · Связь · Коммунальные · Развлечения · Спорт · Питомцы · Путешествия · Наличные · Комиссии банка · Переводы · Доходы · Прочее

Словарь мерчантов настроен на Латвию и Балтию — правится в `js/categories.js` (список `MERCHANT_RULES`).

## Структура

```
index.html        — разметка
styles.css        — стили, светлая и тёмная темы
js/categories.js  — категории и словарь мерчантов
js/parser.js      — парсер CSV-выписок (Swedbank/SEB/Revolut/generic)
js/charts.js      — SVG-графики с тултипами
js/demo.js        — демо-данные
js/app.js         — состояние, фильтры, таблица, localStorage
```

Без сборки, без зависимостей, без сервера.
