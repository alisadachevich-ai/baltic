Перетащи сюда выписку по карте

CSV из Swedbank, SEB, Citadele, Luminor, Revolut — можно несколько сразу; CSV обрабатывается локально в браузере.
PDF-выписки тоже можно: они распознаются через Claude API (нужен ключ — ⚙️ в разделе чеков).

Как выгрузить выписку

Swedbank

Интернет-банк → Konts → Konta pārskats → выбери период → Saglabāt kā CSV.

SEB

Интернет-банк → Konta pārskats → период → скачать в формате CSV.

Revolut

Приложение → счёт → Statement → формат Excel/CSV → выбери период.

Другой банк

Подойдёт почти любой CSV: аппка сама найдёт колонки с датой, суммой и описанием.
